# About

This branch contains the code for HIP UVaFTLE:
- folder `HIP` contains the baseline version of HIP, the Makefile was modified to accomodate the machine's GPU architecture
- folder `HIP-opt` contains the optimized version of hip. Code changes are included, while Makefile modifications are present in `v2.Makefile` as well as `v2.nv.Makefile`. Block size can be re-adjusted in `ftle.cpp`.

# Compile and Run

Instructions on how to compile and run UVaFTLE can be found in the `README.md` of the original repository where this is forked from.
